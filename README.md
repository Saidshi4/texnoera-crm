CRM Application – Texnoera Final Project

Bu layihə Texnoera kursunun final tapşırığı olaraq hazırlanmışdır. Məqsəd, kurs və tədris müəssisələrinin hələ də kağız üzərində apardığı işləri avtomatlaşdırmaq üçün sadə bir CRM sistemi yaratmaqdır.

Layihə vasitəsilə:

Müştəri məlumatlarının idarə edilməsi

Kurs və qrupların qeydiyyatı

Ödənişlərin izlənməsi

Sadə idarə paneli üzərindən əməliyyatların aparılması

İstifadə olunan texnologiyalar: Java, Spring Boot, PostgreSQL, Firebase Cloud Messaging (FCM) – bildirişlər üçün.
